# 2.45 GHz Microstrip Patch Antenna — Ansys HFSS

## Project Overview
Designed a rectangular microstrip patch antenna operating near the 2.45 GHz Wi-Fi band using Ansys HFSS. The objective is to investigate how physical antenna dimensions and feed placement affect resonance, impedance matching, and directional radiation.

## Design Methodology
1) **Analytical design:** Estimated patch width and length using transmission-line antenna theory and FR-4 substrate properties.
2) **HFSS implementation:** Modeled the patch, inset feed, dielectric substrate, and ground plane. Applied a lumped port and radiation boundary.
3) **Geometry optimization:** Adjusted patch dimensions to tune resonance toward 2.45 GHz and improve impedance matching.
4) **EM validation:** Used full-wave simulation to evaluate S-parameters and antenna radiation characteristics.

## Simulation Results

1) **Antenna geometry:** Physical patch and feed layout.
2) **Return loss (\(S_{11}\)):** Resonance and matching near 2.45 GHz.
3) **Radiation pattern:** Directionality and realized gain.

## Results and Interpretation
Investigated how changing patch length shifts resonant frequency and how feed placement affects impedance matching. The full-wave HFSS model allows the antenna's electrical response and radiation performance to be evaluated beyond initial analytical approximations.

The project demonstrates the connection between electromagnetic theory, physical antenna geometry, and RF performance.
